
make custom server using HTTP:


steps :
1.import http module using require().
     const http = require("http");

2.use createServer Method.
    http.createServer((req,res)=>{
        res.writeHead(200,{"content-type" : "text/plain"});
        res.write("Create a Server using HTTP Module.");
        res.end();
    })     


3. assign port
    http.listen(3000);
